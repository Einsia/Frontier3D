# 场景与玩法需求

根据参考图确定开放世界环境的范围、构图与比例。村庄是其中需要精细建模、支持步行探索及交互的重点区域；建筑数量不限定周围地貌的范围。一个方块为 100 Unreal 厘米，Z 轴向上。包括 11 栋不同建筑（8 栋住宅、2 栋铁匠铺、1 栋仓库），至少 8 处可进入且有家具的室内、村庄广场、连通道路、两片带灌溉的农田、牲畜围栏、植被及至少 40 件有用途的道具。环境构图和气质参考图片，不可见部分合理补全。不要求流体模拟、动物 AI、战斗或完整生存系统。

玩家使用具有重力和行走碰撞的 ACharacter，胶囊半径 30 厘米、半高 85 厘米，视点高度约 160 厘米。WASD 移动、鼠标观察、E 交互。交互使用 300 厘米以内且受遮挡限制的视线射线；手动与自动操作走相同的玩法逻辑。

1. 四扇铰链门：house01.door、house02.door、smithy01.door、storehouse.door。门扇可见且有碰撞，0.4–1.0 秒内旋转约 90 度，开启后可通过，关闭后阻挡。运动过程不穿过墙体、家具和邻近物体。其他建筑入口可常开。
2. 两个箱子：house01.chest、storehouse.chest。箱盖可开合，use 操作箱盖、take 取物。住宅箱内初始一份种子，仓库箱内初始一份工具；只能取一次，行走后状态保持，向玩家显示状态。
3. 围栏门 pen.gate：铰链运动且有碰撞，关闭阻挡、开启放行，再次使用可恢复。
4. 六株作物 farm.crop01 至 farm.crop06：harvest 将成熟植株变为已收割状态并给予一份作物；plant 消耗一份种子并显示未成熟植株。已收割或未成熟状态不能重复收获。不测生长计时。
5. 三个可编辑方块 edit.block01 至 edit.block03：位于仓库附近标明的 3×1 区域。remove 同时移除可见几何与碰撞，place 同时恢复。其他地形不可编辑，不使用重建整个世界来代替状态实现。
6. 熔炉 smithy01.furnace：process 消耗携带的一份作物，炉火可见亮起至少一秒，随后给予一份加工品。没有原料时无效果。不能仅用文字或 JSON 标志代替真实效果。
7. 在住宅、农田、铁匠铺、仓库之间步行时，状态保持，不随距离、可见性或时间重置。跨进程存档可选。

隔墙或超距离操作不应激活目标，前置条件由玩法逻辑保证。
