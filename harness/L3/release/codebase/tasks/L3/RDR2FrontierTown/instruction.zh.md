# 荒野大镖客2：瓦伦丁中心街区

以所给参考图作为外观目标，保留可见的空间关系、比例、材质与氛围，对不可见区域作一致补全。完成下述相互连通的环境，并补全协调的周边景观。

复刻参考图中的瓦伦丁街区，将主街、巷道、酒馆、商店、马厩院落和货运场连成可探索的完整地点。匹配地势坡度、木制店面、门廊、阳台、招牌、屋顶轮廓和风化材质。完成酒馆、杂货店、储藏室和马厩内部，布置拴马栏、饮水槽、木桶、堆放货物、围栏和车辙等街道细节，周边衔接植被与乡野地形。

## 可交互环境

实现酒馆摆门、商店双开门、马厩门和两个可抽拉的抽屉。手推车可推动，能装载至少三件不同货物，并在转弯和穿越街道时保持货物随车移动。可开启的货箱内有能单独转移的物品。面粉、工具和瓶装货物分别送到标识明确的储藏位置，保留物品身份和数量。角色在避开门扇运动的位置可以开关马厩门。马匹可为静态，不要求骑乘、战斗和人群模拟。

## 连续操作任务

在货运场取得三类货物并装车，沿街到杂货店开门，将货物卸至对应位置；经马厩院落返回，关上院门，将空车停回货运场。

制作细致且视觉一致的环境，布局合理、路线可达、物品放置稳定、交互反馈清晰。开发时检查外观与功能，遵循随题提供的 L3 生成与交付要求。
