1. 启动实际 UE5 工程，建立装配界面、分级、油门、姿态、轨道视图和存读档的控制映射；观测原生运行状态，不能用替代模拟器完成测试。
2. 构造至少三种连接/分级配置不同的有效设计，测试重复部件、级间与侧向分离、燃料耗尽和重返设计。不要要求固定高度或唯一火箭布局。
3. 测单体引力：读取或从工程提取当前天体 μ 与初态 r、v，独立高精度积分 `a=-μr/|r|^3`。在无推力真空段对比相同时刻位置、速度、比能量 `|v|²/2-μ/|r|` 与比角动量 `r×v`。以特征半径/圆轨道速度归一化，避免近零量作分母。
4. 测动力段：在引力之外检查推力方向、油门和燃料/质量变化；比冲以秒计时检查 `ṁ=T/(Isp*g0)` 与游戏采用的 g0 单位约定一致。无燃料不得有持续推力；分离后不再错误继承被抛弃发动机/燃料。
5. 对有大气环境和真空分别测试降落伞；简化模型允许，但真空不能有空气阻力。没有真实天文尺度、多体引力或登月硬要求。
6. 比较预测轨道、参数显示、实际轨迹；多个基础步实现的时间加速应与等时长正常推进接近。
7. 在点火/分离前后和轨道段保存恢复，比较飞行器、分离体、连接、燃料、姿态、分级及后续轨道。浮点精度与测试时长需统一标定。
8. 记录多设计完成率、恢复率、性能与盲评体验；跨引擎证据政策同体素任务，未取得对应资产时记不可测。

## 数值与报告约定

- 先记录实际单位，再换算：L1 prompt 用 mm、交付几何用 m，0.3 mm = 0.0003 m；不能把 Blender 显示单位当作真实世界尺度。
- Chamfer 统一定义为两方向最近表面距离均值的平均，报告距离本身（不平方），说明采样数、seed、是否面积加权、全局对齐方法。分组件平均与整体面积平均要区分。
- 体积 IoU = 交集体积/并集体积，必须注明解析/布尔/体素方法与体素尺寸。先检查闭合性；不闭合几何无法可靠测体积时报告不可测及拓扑失败，不编造 0 分或 1 分。
- 关系满足率 = 满足的适用关系数/全部适用关系数；语义缺件不能通过减少分母获益，缺失的必需关系记失败。对无法观测项保留数量和原因。
- 随机测试记录 seed、采样分布、操作序列、场景/硬件/版本和预算。同一方法跨模型保持固定；不同协议不能混排行。
- 视觉比较固定相机政策、分辨率和色彩流程，材质/风格评分不代替几何与状态指标。图像特征模型、版本、预处理、rubric 和阈值均需记录。
- 局部编辑先确定目标区域，再分别报告目标质量和非目标保持。正常投影、阴影或反射变化不能单凭像素差当作非目标编辑。
- 参数可读性、外观偏好等辅助结果与程序化主指标分列。生成过程的 token、时间、工具/渲染次数由 Harness 记录，不由模型自报。
