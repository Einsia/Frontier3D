# Evaluation reference

没有参考游戏或唯一飞行轨迹；按提交游戏的参数做独立物理校验，solution/ 仅有评测参考。

| 维度 | 指标 | 如何测量 | 报告结果与判定 |
| --- | --- | --- | --- |
| 可执行性 Executable | 工程启动与稳定性 | 在声明引擎版本和统一机器上构建/打开工程，启动默认关卡并完成设计、试飞、返回设计的循环。 | 启动成功率、运行错误、崩溃/软锁次数和连续运行时长；检查工程资源与依赖完整。 |
| 结构 Structural | 部件覆盖与自由组合 | 核对燃料箱、发动机、指令舱、两类分离器和降落伞的不同规格；重复安装同型号，检查连接图和分级可编辑性。 | 类别/变体覆盖、有效连接比例、重复安装成功率及分级编辑成功率；不要求固定部件 ID 或连接数据结构。 |
| 任务与状态 Task & State | 分级、控制与分离 | 用不同分级方案测试油门、姿态、点火、级间分离、侧向分离和开伞，观察分离前后连接、质量与推力来源。 | 动作成功率、事件顺序符合率、残留连接/错误推力/错误质量次数；分级次序由玩家设计。 |
| 几何 Geometric | 单体引力轨道精度 | 在无推力真空段，根据游戏使用的中心天体参数和初态建立独立高精度积分参考，比较位置/速度、比机械能和比角动量漂移。 | 归一化位置/速度误差、能量/角动量相对漂移及轨道周期误差；统一仿真时长、误差归一化和容差，不能在有推力或阻力段强求能量守恒。 |
| 几何 / 任务状态 | 推力、燃料与质量自洽 | 按实际部件参数检查推力随油门变化、质量随燃料消耗下降，以及质量流率与推力、比冲的关系；检查燃料耗尽停止推力。 | 推力/燃料/质量误差、负燃料与无燃料推力次数；简化尺度允许，但单位与参数关系须一致，不强制真实航天器数值。 |
| 几何 / 任务状态 | 降落伞与环境规则 | 在有大气条件与真空分别测试开伞，核对声明适用条件及阻力响应；检查分离体继续运动和碰撞行为。 | 适用条件符合率、真空错误阻力、分离体消失/状态异常次数；不强制多体引力、真实地形或登月。 |
| 视觉 / 任务状态 | 星体、轨道视图与参数 | 核对太阳、地球和月亮；对比轨道线、关键参数与当前飞行器状态，检查切换视图和分级后显示更新。 | 星体覆盖、轨道线预测误差、参数显示误差、状态更新延迟；概念图不作像素或尺度真值。 |
| 任务与状态 Task & State | 多设计可玩性与失败恢复 | 构建至少 3 种不同有效飞行器，覆盖不同连接/分级组合，执行试飞并从失败返回设计或恢复存档。 | 有效设计数、各设计的组装/启动/控制完成率、失败恢复率与软锁数；不强制唯一设计、固定高度或统一通关轨迹。 |
| 任务与状态 Task & State | 存档与重复运行一致性 | 在飞行和分离后保存恢复，比较飞行器、分离体、连接、燃料、姿态、分级及轨道；同初态回放相同操作。 | 恢复成功率、物理状态误差、离散状态不一致数及继续飞行差异；浮点状态按标定精度比较，不要求逐字节一致。 |
| 结构 / 任务状态 | Blender + UE5 内容与语义一致性 | 检查部件外观、连接位置、尺度、碰撞及操作语义在 UE5 内一致；能从评测过程取得 Blender 对应资产时做双侧比较。 | 资产—连接—碰撞一致性和跨引擎可比项差异；无双侧证据记不可测，不追加迁移报告或指定中间文件。 |
| 视觉 Visual | 操作理解与探索体验 | 盲评部件选择、分级列表、燃料/姿态/轨道反馈是否清楚，以及失败原因能否理解、能否方便再设计。 | 界面反馈与可理解性辅助评分、人工偏好及具体阻碍；与客观物理和任务指标分列。 |
| 可执行性 / 效率 | 物理步长与运行性能 | 统一硬件及飞行器部件负载，核对 20 Hz 基础物理步；比较正常速度与多个基础步时间加速的同终点状态。 | 步长符合性、加速前后状态误差、帧时间分位数、峰值内存；时间加速不得通过直接跳过基础物理过程实现，性能阈值待标定。 |
| 效率 Efficiency | 生成成本与反馈收益 | Harness 记录总耗时、token、工具调用、渲染次数及失败重试；若采用视觉反馈，分别记录初稿、每轮修改与最终结果，单次生成和最多 3 轮修改分组比较。 | 报告总成本、各轮指标变化及每次质量改善的额外成本；固定模型设置、环境和预算，不把失败运行从成本统计中删除。预算与综合权重待标定。 |

阈值依据英文 instruction；未明示项须在正式比较前标定。程序化、视觉辅助与人工结果分列，不合成未经校准的总分。运行失败保留原因；原生资产自检不代表完整 evaluator 已实现。

## 视觉参考的评测边界

`input/reference.png` 是模型已知的视觉方向，不是隐藏 GT。评测场景造型、配色协调、主体辨识度、相机可读性及交互反馈；使用提交 UE5 工程的实际运行画面核验。不得以逐像素相似度、图中任意物体位置或 HUD 样式作为硬性通过条件，也不能把概念图当作真实物理状态。文字规格优先，画面评分与规则/物理评分分开报告。
