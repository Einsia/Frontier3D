# 具身：维修工坊与室外物流场

以所给参考图作为外观目标，保留可见的空间关系、比例、材质与氛围，对不可见区域作一致补全。完成下述相互连通的环境，并补全协调的周边景观。

复刻参考图中的维修工坊，并合理设计相连的室外物流场，匹配建筑、工作位、设备、储藏、场地表面及材质磨损。连通零件库、两处不同工作台、包装区和室外托盘区。布置可信的工具架、工作台、柜体、夹具、线缆、容器和装配中物件，使零件能够搬运、托盘车能够经过装卸门。

## 可交互环境

实现两个抽屉、可锁工具柜、台钳、可调高度工作台、装卸门和托盘车。底座、支架、两个紧固件及适配工具均为独立可移动物品。台钳固定底座后，且持有工具时，才可安装并固定支架；松开台钳后能作为一个整体取下装配件。工作台升降时保持承载物，托盘车可接合、举起、运输和放下装着成品的托盘。

## 连续操作任务

解锁工具柜、取零件、夹紧底座、安装并紧固支架，松开后检查并包装成品，再用托盘车经装卸门运到室外指定货位；归还工具，将托盘车货叉放下后停好。

制作细致且视觉一致的环境，布局合理、路线可达、物品放置稳定、交互反馈清晰。开发时检查外观与功能，遵循随题提供的 L3 生成与交付要求。
