# L3 生成与交付要求

提交完整、可编辑、可运行的 UE5 工程。实际生成输入为英文题面、本文档及题包公开输入。可按需使用离线素材库，也允许修改或自制材质，记录素材来源。执行期间不联网下载素材，不导入完整答案场景。

实现可控制的角色并使用随附的公开交互组件，手动操作和自动调用走同一逻辑。交互必须改变真实几何和碰撞，并在会话内保留物品身份与状态。不可用、超距或被遮挡的操作应拒绝。必需路线可通行，物体有支撑，活动部件避开非预期穿透。不要求跨进程存档。

Agent 自主编译、运行、查看多视图渲染并测试交互。Harness 记录含重试在内的生成耗时、模型、资源预算及已回传 token 用量，时间预算由具体运行配置指定。交付 project/、源码及所需素材、README.md、assets_used.json、接口绑定以及真实最终预览，覆盖总览、各功能区、室内和关键交互。说明启动、控制、初始状态、操作前置条件和限制。

所有视角呈现同一连贯场景，尺度、几何、材质绑定、纹理、光照及天空或背景协调。截图题以所给图像为外观目标，对不可见区域合理补全；增加的交互设施应融入环境。文字题按题面设计布局，没有隐藏参考图片。
