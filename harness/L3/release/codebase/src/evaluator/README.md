# Shared evaluator implementation

This copy supplies modules imported by the L3 verifier. Run L3 from the public
repository root using [the L3 runbook](../../../README.md).
The supported L1/L2 CLI and its current formulas are documented in
[the root scoring guide](../../../../../../docs/en/scoring.md).
Historical scalable-v1 experiments and their private run directories are not
installation inputs. Use the root `python -m benchmark` commands for L1/L2.
