# 评测接口：综合力量训练器

本题为单视图静态重建。重点为：承重框架、坐垫靠垫、杠杆和把手、滑轮拉索、配重或阻力外壳、支脚与连接。

## 数据边界

模型只收到 instruction.md 与 environment/input/（运行时挂载为 input/）。solution/ 包含原始 GLB、许可来源和新生成的参考 Blender/GLB/视图，仅供评测。不得将源网格、贴图或额外私有视角交给被测模型。中文稿是等价筛选说明。参考几何沿用所选真实资产，不是重新生成的替代物；源缺陷不是提交必须模仿的条件。

单视图未展示的背面和底部只能检查合理性，不能按私有其他视角强求唯一形状。

## 评测方法

| 维度 | 读取与检查 | 边界 |
|---|---|---|
| 执行与交付 | 干净 workspace 按题面命令运行；五个固定产物均有效；打开 Blender 和 GLB，原生重渲染 | 只交图片、缺几何或依赖已有输出不能通过交付检查 |
| 尺度与比例 | 世界坐标真实顶点的包围盒最大跨度；目标 1 m、容差 2%；比较主体与附件比例 | 排除相机灯光；在静态第 1 帧测量；形状对齐不能用额外缩放掩盖尺度错误 |
| 三维形体 | 给定相机轮廓 IoU、可见表面双向采样距离、法线角差 | 只做整体刚体对齐，不逐件独立配准；不要求源拓扑或源网格缺陷 |
| 结构与编辑性 | 逐区域检查厚度、凹凸、孔隙、连接和可分离语义部件；BVH/截面探针 | 有机表面允许单一连续网格，不能按对象名或对象数评分 |
| 细节覆盖 | 下方语义区域分别记录可见形状与关系覆盖，然后宏平均 | 防止大面片淹没小部件；题面允许简化的细字与微小磨损不设硬门槛 |
| 材质与构图 | 从原生场景重渲染，比较主要区域颜色、材质类别、曲面明暗与视图 | 不能以像素总分替代几何测量；须考虑光照与材质格式差异 |
| 跨格式一致 | 独立导入 GLB，比较各要求姿态的包围盒和采样几何；main.png 对照原生重渲染 | 不能用不同模型分别交图片、Blender 与 GLB |
| 重复性与成本 | 两次干净运行，记录几何/图像差异、时间、token、工具调用与重试 | 质量和成本分开；不比较 Blender 二进制字节是否相同 |

## 局部区域

1. 承重框架
2. 坐垫靠垫
3. 杠杆和把手
4. 滑轮拉索
5. 配重或阻力外壳
6. 支脚与连接

本题提供资产来源、原生参考和渲染。生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。下列几何接口说明不代表全部指标均已实现；实际覆盖、容差和视觉区域以逐题评分合同为准，校准限制须单列。

## 材质与测量范围

只允许纯色和程序化材质；禁止将参考图、位图、HDRI、图像或视频输入用于渲染场景。Noise、Bump 等合法程序化节点可用。GLB 必须可读取且包含几何；跨格式或跨 seed 的几何差异保留诊断，继续核查真实执行与依赖。辅助公开视图用于建模，主图以外的视图仅在逐题合同要求时参与评分。

## 评分

本题最终得分：`50% main_image + 20% localization + 20% vlm + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
