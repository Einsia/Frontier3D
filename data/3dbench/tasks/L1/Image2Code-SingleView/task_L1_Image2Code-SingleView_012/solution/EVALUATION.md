# 评测接口：花纹浮雕宝箱

本题是单视图静态曲面重建。主要检查：箱体比例和拱盖曲率、盖体接缝、包边与箍带、花纹饰片的厚度和孔隙、中央锁扣、侧把手和连接座。不使用原对象名、网格数量或顶点对应关系作为正确性标准；不要求爆炸状态、运动或内部机构。

## 数据边界与读取

模型只收到 instruction.md 和 environment/input 下的文件，运行时将后者挂载为 input/。instruction.zh.md、solution/、task.toml 及本文由评测侧持有。solution/reference/scene.blend 是从原模型保留几何、冻结展示姿态并统一尺度后的 GT，材质已打包；scene.glb 是便携参考，main/front/side/top.png 为同一原生场景渲染。audit.json 保存来源哈希、归一化与相机参数。solution/source/ 保存下载的原模型及其 CC0 贴图。

启动前建立干净 output/，仅放生成模型提交的 solution.py、辅助代码及自制 assets/。执行 instruction 中的固定命令，读取 output/scene.blend、scene.glb、main.png、README.md。禁用下载源资产，审计文件访问；不得让模型读取 solution/。入口退出码、stderr、生成耗时和产物校验结果由 runner 记录，不依赖模型自报。

## 指标表

| 维度 | 指标与读取对象 | 建议实现与计分边界 |
|---|---|---|
| 可执行与交付 | 入口退出、五个固定文件、可打开的 Blender/GLB、1000×1000 PNG | 在清洁副本重跑；重新打开原生场景并渲染。无几何、缺主产物、只交图片不得判为完成。 |
| 三维完整性与编辑性 | 有限非零包围盒、有效网格面、合理厚度和可编辑语义部件 | 多个审计角度查看实体、BVH 和截面检查；有机曲面允许连续单网格，不能按部件名字打分，不强求所有扫描网格闭合。 |
| 尺度与整体比例 | 最大跨度相对 1 m 的误差，主体/附件比例 | 排除相机灯光后用世界坐标顶点包围盒；最大跨度容差 2%。形状比较只作一次整体刚体配准，不逐部件配准，不缩放掩盖尺寸错误。 |
| 形状恢复 | 给定视图轮廓 IoU、可见面双向距离、法线夹角分布 | 从私有 Blender 场景读取相机并重渲染掩膜/深度/法线；表面均匀采样，距离除以 1 m。只以公开主图可见表面为精确 GT；另外三张私有图仅帮助检查三维合理性，不能要求隐藏背面与源模型唯一一致。 |
| 局部曲面与细节 | 下方六个区域的几何/轮廓/法线与可见结构覆盖 | 逐区域统计后等权宏平均，避免箱体或底座面积淹没细节分数；主要凹凸与孔隙需要几何，细纹允许材质表达。 |
| 关系与结构 | 连接、接触、层叠、明显穿插或悬空 | 按题面对应区域取截面或 BVH 距离，允许合理接合；机器人整体悬浮不算未支撑。不能把源扫描缺陷变成提交必须复刻的条件。 |
| 视觉一致性 | 主材质类别、区域色差、粗糙度观感、主图构图 | 使用提交原生场景重渲染，与任务参考区域对比；可记录颜色差和图像差作为分项，受光照影响，不能只用像素总分。微小绘画、旧化、细刻线不做硬门槛。 |
| 跨文件一致 | Blender 与 GLB 的形状/姿态/尺度，main.png 与重渲染 | 将 GLB 导入独立空场景比较包围盒与采样面；允许材质格式差异，不允许用不同模型交付 PNG 和原生场景。 |
| 稳定性与成本 | 两次清洁运行的几何/图像差异、时间、token、调用和重试 | 记录 runner 观测值；质量和资源成本分别报告，按语义结果比较，不按 Blender 文件字节哈希。 |

## 局部区域

1. 箱体比例和拱盖曲率：以公开视图中可见部分为范围，记录轮廓、曲面和关键间隙是否恢复。
2. 盖体接缝：以公开视图中可见部分为范围，记录轮廓、曲面和关键间隙是否恢复。
3. 包边与箍带：以公开视图中可见部分为范围，记录轮廓、曲面和关键间隙是否恢复。
4. 花纹饰片的厚度和孔隙：以公开视图中可见部分为范围，记录轮廓、曲面和关键间隙是否恢复。
5. 中央锁扣：以公开视图中可见部分为范围，记录轮廓、曲面和关键间隙是否恢复。
6. 侧把手和连接座：以公开视图中可见部分为范围，记录轮廓、曲面和关键间隙是否恢复。

本题提供资产来源、原生参考及公开参考图。生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。表面采样、区域掩膜等接口描述须与实际配置区分；报告已实现指标及其覆盖范围，视觉判断不能替代精确几何测量。感知阈值保留校准限制。

## 材质与测量范围

只允许纯色和程序化材质；禁止将参考图、位图、HDRI、图像或视频输入用于渲染场景。Noise、Bump 等合法程序化节点可用。GLB 必须可读取且包含几何；跨格式或跨 seed 的几何差异保留诊断，继续核查真实执行与依赖。辅助公开视图用于建模，主图以外的视图仅在逐题合同要求时参与评分。

## 评分

本题最终得分：`50% main_image + 20% localization + 20% vlm + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
