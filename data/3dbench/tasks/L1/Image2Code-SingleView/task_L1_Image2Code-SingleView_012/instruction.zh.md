# 花纹浮雕宝箱

仅根据 input/reference.png 重建完整三维物体，不提供其他视图或初始模型。匹配可见表面，背面与底部合理补全，不凭空增加内部机构。

重建图中闭合的木宝箱。保留矩形下箱体、连续拱起的箱盖、盖体接缝、金属包边与箍带、凸起花纹金属片、中央锁扣，以及可见侧把手及连接座。金属饰片应高于木面，有可读厚度及主要镂空或凹陷，不能将全部装饰替换为平面照片。匹配主要木材、暗色金属及可见箍带花纹的重复关系。细木纹、划痕和细刻线可简化。箱盖与下箱体应能作为不同部件编辑，但不要求开盖动画或不可见的箱内结构。

使用 Blender 建立真实、可编辑曲面。匹配轮廓、连续曲率、主要凹凸、厚度、间距与遮挡。有机曲面可以是连续网格；确实独立的部件应组织为可编辑对象或清楚分离的网格岛。不要求复刻源拓扑、顶点数、对象名称和微小纹理细节，不能用图片平面或只朝相机一侧的薄壳代替完整几何。

将物体最大整体跨度（不含灯光和相机）设为 1.000 m，容差 2%。这是任务尺度约定，并非实物测量。其他比例从参考图推断，使用米制和 Z 向上。第 1 帧保存最终静态姿态，不要求动画、爆炸图或仿真。scene.glb 导出相同姿态。以匹配 reference.png 的相机、普通摄影棚灯光、Cycles、AgX 和曝光 0，渲染 1000 × 1000 的 main.png，并把相机照明保存在 scene.blend 中。

## 固定交付结构
所有交付文件放在任务工作目录的 `output/` 下，评测器读取以下固定路径：

```text
output/
  solution.py       # 可复现的 Blender 生成入口
  scene.blend       # 可编辑原生场景，第 1 帧为最终静态姿态
  scene.glb         # 相同静态姿态的几何和材质
  main.png          # 1000 × 1000 主视角渲染
  README.md         # 运行、依赖与材质说明
  assets/           # 可选的本地辅助代码及程序生成纹理
```

在干净工作目录中执行：
`blender --background --factory-startup --python output/solution.py -- --input-dir <workspace>/input --output-dir <workspace>/output`

入口应不依赖上次生成的输出，重新生成或刷新 scene.blend、scene.glb 和 main.png。辅助文件相对脚本定位，只使用给定输入、自行随包交付的资源/代码及已安装库。不能联网获取源网格、贴图或额外源视图，也不能将外部取得的源网格编码塞入脚本。不能使用个人机器的硬编码路径。将依赖打包到 Blender 文件，或使用 output/assets/ 下的可移植相对路径。其他渲染和日志分别放在 output/renders/ 与 output/logs/。

## 材质约定

仅使用纯色或程序化材质。参考图用于观察；场景、材质、灯光、几何节点及合成不得使用位图、HDRI、烘焙或生成的图像。允许 Noise、Bump 等程序化节点。
