# 评测接口：双轴相机托架

私有 spec.json 描述基准几何，几何标注不暴露给模型。零件名称自由，按形状和空间关系匹配，对称同类件允许置换。GT 为 19 件；authoring 为作者构造实现，不是参评答案。

| 维度 | 需要测什么 | 实现方式与边界 |
|---|---|---|
| 可执行性 | 固定入口、原生工程和 GLB 有效 | 清洁环境运行约定命令；重开重渲染，查相对路径和依赖。 |
| 结构 | 零件数量、闭合连通、语义层级 | 分离实体，按尺寸和配合匹配；不按作者对象名、顶点顺序判断。 |
| 几何 | prompt 的尺寸、孔径、台阶、盲孔与贯通关系 | 拟合平面和圆柱、截面、解析占用探针，尺寸容差 0.3 mm。不能只比较包围盒。 |
| 装配 | 同轴、孔轴对应、指定间隙和接触 | 统一刚体对齐后检查相对变换与表面距离，位置容差 0.3 mm；不逐零件单独配准。合理规定间隙不算悬空错误。 |
| 双状态 | 帧 1/61 几何保持与恢复 | 检查帧 61 各零件仍完整可辨，返回帧 1 恢复；不硬匹配作者爆炸位置。GLB 对齐帧 1。 |
| 视觉 | 材料类别和三维可读性 | 从原生场景重渲染；不比较未指定的相机、背景、光影。 |
| 效率与稳定 | 时间、token、调用、重试和复现 | Harness 记录完整过程，质量与资源消耗分开报告。 |

qa.json 已对每个零件做闭合连通检查和 512 个随机解析 CSG 占用探针；这验证参考数据，不表示 evaluator 已实现或模型已通过。场景级装配验收仍须依据 prompt 中配合关系设置确定性探针。

评测侧可从任意路径重建 GT：`blender --background --factory-startup --python solution/rebuild_reference.py -- --output-dir <new-directory>`。此入口和 reference/spec.json 均保持私有。

## 评分

本题最终得分：`60% vlm + 30% data + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
