# 评测接口：环槽回转套筒

| 维度 | 指标 | 方法 |
|---|---|---|
| 交付与复现 | 固定文件和入口有效 | 清洁运行、重开工程、对齐 Blender 与 GLB；不允许私有 GT 输入。 |
| 实体结构 | 一件闭合连通实体 | 流形边、连通分量、正体积与自交检查。 |
| 尺寸形状 | prompt 尺寸及特征 | 以 STEP 为私有原生 GT，拟合轴/截面、检查槽肩或扫掠截面、表面距离；容差 0.15 mm。 |
| 几何关系 | 贯通孔与连续壁，或连续路径及截面朝向 | 截面与射线/体积探针；不能用包围盒代替。扫掠的插值器已在 prompt 明示，不将未定义曲线规则作隐藏要求。 |
| 可编辑与视觉 | 可编辑真实几何、指定材料 | 原生重渲染辅助诊断，不比较未指定相机和背景。 |
| 效率稳定 | token、时间、工具调用及重试 | Harness 完整记录，质量与成本分开。 |

OCC 已验证正体积的有效单实体；原生 Blender 的连通性、体积差验证另存。当前没有 evaluator 实现或模型实测成绩。

## 评分

本题最终得分：`60% vlm + 30% data + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
