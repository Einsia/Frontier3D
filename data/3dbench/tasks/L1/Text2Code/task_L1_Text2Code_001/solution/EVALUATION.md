# 评测侧说明

reference/spec.json 和 scene.blend 是私有完整 GT，绝不作为模型规格输入。尺寸要求已完整写入 prompt，零件命名自由。

| 维度 | 指标 | 方法 |
|---|---|---|
| 可执行性 | 固定文件与入口复现 | 清洁环境运行 instruction 中 Blender 命令，打开场景及 GLB；核对依赖不超出工作区。 |
| 结构 | 11 件独立闭合连通零件 | 根据形状、尺寸和装配关系匹配 2 法兰、1 轴、4 螺栓、4 垫圈；允许同类对称件置换，不依赖私有名称。 |
| 几何 | 零件尺寸、孔径、节圆、六角头和厚度 | 几何测量结合横截面与穿孔探针；尺寸容差 0.3 mm。非流形、实体体积与多余组件单列。 |
| 装配 | 同轴、孔轴对齐、2 mm 面间隙、贴合与穿透 | 原点可不同，只允许统一平移及绕竖轴旋转对齐，不允许逐件配准。位置容差 0.3 mm；检查垫圈上下接触和贯穿轴的端部伸出。 |
| 状态 | 帧 1 装配、帧 61 爆炸、形状保持 | 帧 61 不比较作者选择的爆炸坐标，只检查间隔可辨、各件形状保持和帧 1 可恢复。GLB 与帧 1 一致。 |
| 视觉 | 材料类别与装配可读性 | 统一视角下检查蓝灰法兰、银色轴螺栓、黄铜垫圈；不把作者渲染相机或背景当作模型隐藏要求。 |
| 效率 | 时间、token、调用和重试 | Harness 记录完整轨迹，包括失败成本。 |

qa.json 记录参考模型与解析 CSG 的随机占据采样检查，不能证明所有装配关系均正确。原生测量覆盖见 `../harness/eval_spec.json`；最终评分见[评分说明](../../../../../../../docs/cn/scoring.md)。孔道、装配与角色材质等精确语义须与视觉判断区分，逐项报告实际覆盖和校准限制。

## 评分

本题最终得分：`60% vlm + 30% data + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
