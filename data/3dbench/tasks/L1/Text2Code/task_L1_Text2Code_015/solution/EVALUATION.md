# Evaluation reference

完整装配体、评审图和几何标注；按相对几何评分，允许自由原点与爆炸布局。

| 维度 | 指标 | 如何测量 | 报告结果与判定 |
| --- | --- | --- | --- |
| 可执行性 Executable | 代码与文件可用性 | 从空工作目录运行程序，打开原生工程，导入装配态 GLB，检查单位、坐标朝向和依赖。 | 执行、加载、导出成功率及错误类型；缺失交付项单列。 |
| 几何 Geometric | 尺寸与孔位精度 | 测量法兰、轴套、轴、隔圈、垫圈及螺栓的直径和厚度；测量分度圆直径、三个孔的 120° 分布及上下孔对齐。 | 逐项误差（mm/度）；长度尺寸按 0.3 mm 容差判定，孔位通过空间偏差判定，角度误差另报。 |
| 几何 Geometric | 相对装配精度 | 测量共轴性、法兰中面相距 22 mm、轴中心相对位置、隔圈居中、垫圈贴合和螺栓穿孔；检查轴之间及端面之间的间隙。 | 相对位置误差、关系满足率及不合理干涉；装配位置按 0.3 mm 容差，不检查任意绝对原点。 |
| 几何 Geometric | 形状与拓扑 | 匹配 11 个语义零件后，检查闭合、连通、非流形边和有效体积；全装配统一对齐后计算 Chamfer/IoU。 | 有效实体比例、缺件和重复件数、Chamfer（mm）、IoU；采样与体素精度统一，形状分数阈值待标定。 |
| 结构 Structural | 装配层级与参数表达 | 检查 11 件分别可编辑、层级可理解；核对关键尺寸能否在建模程序中追溯，程序运行是否生成交付几何。 | 部件/层级符合率、重现差异，参数组织与可读性辅助评价；不要求特定变量名、特征树或作者代码结构。 |
| 任务与状态 Task & State | 完整文字约束满足 | 将 prompt 中的部件、颜色、装配关系和交付要求拆为评测侧检查项，对每项保留测量证据。 | 满足项/适用项、失败约束清单；避免按表格行数任意加权，尺寸和装配等子项分别报告。 |
| 任务与状态 Task & State | 两种展示和导出一致性 | 对比装配帧、爆炸帧及恢复后局部几何与件数；比较 GLB 与原生装配状态。 | 形状保持率、恢复误差、导出几何/材质差异；拆分距离与方向自由，爆炸清晰度作辅助评价。 |
| 视觉 Visual | 结构可读性与配色 | 在固定评测视角观察轴、法兰、连接件是否清楚，材质分配是否符合文字；检查爆炸视图是否解释部件关系。 | 遮挡与材质检查、盲评结构可读性；不与评审用示意图做逐像素一致性排名。 |
| 效率 Efficiency | 生成成本与反馈收益 | Harness 记录总耗时、token、工具调用、渲染次数及失败重试；若采用视觉反馈，分别记录初稿、每轮修改与最终结果，单次生成和最多 3 轮修改分组比较。 | 报告总成本、各轮指标变化及每次质量改善的额外成本；固定模型设置、环境和预算，不把失败运行从成本统计中删除。预算与综合权重待标定。 |

阈值依据英文 instruction；未明示项须在正式比较前标定。程序化、视觉辅助与人工结果分列，不合成未经校准的总分。运行失败保留原因；原生资产自检不代表完整 evaluator 已实现。

## 评分

本题最终得分：`60% vlm + 30% data + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
