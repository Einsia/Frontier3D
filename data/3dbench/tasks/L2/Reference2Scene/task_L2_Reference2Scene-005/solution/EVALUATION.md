# 评测设计：俯视城市街区与多层建筑群

生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。本文件说明检查范围；实际实现及分项定义以逐题合同为准，不预设指标已完成人工校准。

## 可执行性与提交

在隔离的干净工作区按 instruction 命令运行 solution.py，检查 manifest 的所有提交文件、原生 scene.blend、相机及贴图依赖；复渲染确认图像来自场景。输出尺寸、Cycles、AgX、曝光、相机局部平移按照 instruction 验证。完整照片平面替代、未建模的单视角投影和缺少主要结构为失败证据。

## 场景核对

重建斜俯视城市的高低建筑、分隔街区、交叉道路、重复窗格与屋顶设施。保留路网、相对占地与高度、退台、屋顶轮廓及前景遮挡；微小车辆和远处窗格可简化，建筑须是独立可编辑体块且街道真实留空。

先核对构图、主要物件覆盖、相对尺寸与遮挡，再检查几何厚度、可编辑性、物体间隙、材质与光照。允许 instruction 中明确的细节简化。尺度采用题目约定，不比较无标定真实尺寸。视觉判断及几何判断分别记录证据；未实现的几何指标不视为已测量，感知分数保留校准限制。

reference/scene.blend 与 main.png 为评测侧源场景和主图，alternate.png 是对应的偏移相机参考。由于模型仅得单图、未给标定尺度，几何比较须先对齐相机与尺度，未知表面不应按私有源网格唯一值扣分。扫描模型可能包含破洞、烘焙光照和无语义连通网格，不要求逐顶点或逐对象名称复刻。

## 评分

本题最终得分：`50% main_image + 20% localization + 20% vlm + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。

本题使用专用视觉分项：`main_image = 0.5*city_layout + 0.5*city_buildings; vlm = 1*city_facades; detail = 1*city_roofs`. 定位分和总分权重保持上述定义。
