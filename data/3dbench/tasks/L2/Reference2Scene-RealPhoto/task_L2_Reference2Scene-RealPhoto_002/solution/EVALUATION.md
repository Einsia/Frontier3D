# 评测设计：MessyKitchens：水槽旁杂乱杯碟重建

生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。本文件说明检查范围；实际实现及分项定义以逐题合同为准，不预设指标已完成人工校准。

## 可执行性与提交

在隔离的干净工作区按 instruction 命令运行 solution.py，检查 manifest 的所有提交文件、原生 scene.blend、相机及贴图依赖；复渲染确认图像来自场景。输出尺寸、Cycles、AgX、曝光、相机局部平移按照 instruction 验证。完整照片平面替代、未建模的单视角投影和缺少主要结构为失败证据。

## 场景核对

重建白色厨房台面、嵌入式深色水槽和画面中可见的黑色灶台边缘。按图摆放深蓝色深盘、木勺、圆形木板、直立紫色马克杯、白色碟子、侧放白色杯、倾斜浅蓝色杯及侧放深蓝色杯。匹配物件的相对尺寸、朝向、间距、遮挡，以及与台面或木板的接触关系。器皿须有中空内部、杯盘口沿、底部及可见把手；水槽须有深度，台面和木板须有厚度。保留白、蓝、紫和木色材质对比、陶瓷反光及俯斜视构图。小标志和远处背景家具可简化。

先核对构图、主要物件覆盖、相对尺寸与遮挡，再检查几何厚度、可编辑性、物体间隙、材质与光照。允许 instruction 中明确的细节简化。尺度采用题目约定，不比较无标定真实尺寸。视觉判断及几何判断分别记录证据；未实现的几何指标不视为已测量，感知分数保留校准限制。

没有真实三维 GT；不要把人工重建、估计深度或任意物件坐标标记为 ground truth。偏移视角主要检查三维结构，未知背面按合理性审核。

本题仅提供一张实拍参考，没有隐藏第三张照片。alternate.png 为规定的相机偏移视图，仅检查几何体积、遮挡、支撑与视角一致性，不作为未知真实视角的像素匹配目标。
