# 人形测试场·障碍段中途

人形测试场·障碍段中途 设计机器人测试场里一段人形机器人通过障碍的赛道，采用顺赛道方向的斜上方长视角。测试场约 10 × 4 米，地面为蓝色运动地胶并施划白色赛道边线，赛道标线宽 1.20 米（±20 毫米），沿全程连续；末端扶手段按另列的 0.90 米净宽验收。赛道要素依次布置：入口标线后一段 15° 坡道（坡长 1.50 米、宽 1.20 米，坡面防滑条纹）；接三级台阶，每级高 0.15 米（±5 毫米）、踏面深 0.30 米、级间一致；接一条跨越沟，沟宽 0.45 米、深 0.30 米，沟沿倒角、沟内涂警示黄；接五根绕桩，桩径 0.08 米、高 0.50 米，相邻桩横向错位 0.40 米、纵向间距 0.80 米；最后是一段扶手走廊，长 2.00 米、净宽 0.90 米，两侧扶手高 0.90 米、直径 0.04 米、立柱间距不超过 0.80 米。人形机器人（身高 1.30 米、肩宽 0.40 米）冻结在第一级台阶上：前脚掌踩上第一级踏面、足尖越沿不超过 30 毫米，后腿仍触坡道面、膝关节弯曲约 60°，躯干前倾 8°（±2°），双臂一前一后摆开维持平衡，头部摄像头朝向下一级台阶。赛道边立三盏补光灯柱（高 1.80 米）与一台三脚架摄像装置，起点与终点各设标牌。可通行验收：赛道边线内侧除设计障碍外无任何杂物侵入，坡道两侧留 0.30 米安全边距。可触及验收：台阶各级前沿、绕桩桩位均落在赛道中线 0.60 米带内。可操作验收：机器人足底与坡道、台阶接触面贴合穿透不超过 3 毫米，几何平衡代理（躯干竖直延长线，不作为真实重心或动态稳定性证明）落在前脚支撑面内偏差不超过 0.05 米。使用灰黑机身配橙色关节标识，场地背景为素色围挡，均匀高天棚灯加灯柱补光。主视角沿赛道把坡道、台阶上的机器人与后续障碍串进同一纵深画面。这是可编辑静态场景，不要求步态仿真、跌倒或传感器数据可视化。

使用米制、Z 向上。创建可编辑、有实体厚度、合理支撑且语义部件可分离的三维几何。机器人须呈现指定关节结构与末端执行器的静态姿态，不要求控制器、动力学或操作轨迹。工作球用于几何可达包络核对，不等于逆运动学或动力学可行性证明。将当前冻结接触与其他服务目标区分，在场景及 README 标注服务点，不另放重复机器人。通行净宽以排除正在验收的机器人后的自由路径计入，其他家具及突出物全部计入障碍；在 README 给出路径采样点与测量口径。不能用照片平面替代完整场景。
