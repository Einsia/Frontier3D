# Evaluation reference

工地原模型和渲染仅为设计示例；没有唯一正确布局，不做真值像素/几何匹配。

| 维度 | 指标 | 如何测量 | 报告结果与判定 |
| --- | --- | --- | --- |
| 可执行性 Executable | 程序、场景和渲染可用性 | 按指定种子运行 solution.py，打开带完整资源的场景并用两个保存相机重渲染。 | 执行/加载/渲染成功率、缺失资源数；检查米制、Z 向上和 1280×960 输出。 |
| 结构 Structural | 场景内容与分区完整性 | 按语义核对未完工建筑、塔吊、两类车辆、堆料区、临时道路、围挡和入口，并检查施工、运输、堆料的组织。 | 必需类别覆盖率、缺失内容、分区关系满足率；不以对象总数或作者节点名计分。 |
| 几何 Geometric | 场地与物体比例 | 测量场地范围及车辆、建筑、设备之间的尺度比例，检查约 40×30 m 的场地要求。 | 场地尺寸偏差、明显比例异常清单；“约”的接受区间需在正式跑分前标定，不临时当成毫米级硬约束。 |
| 几何 Geometric | 道路净宽与入口连通 | 提取实际可通行道路区域，测量入口到作业区路径上的净宽及障碍；使用几何净空或等价扫掠检查，不能仅检查道路对象外框。 | 最窄净宽（要求至少 4 m）、入口到作业区可达率、阻塞位置；可通行路径存在为核心，不限定作者路线。 |
| 几何 Geometric | 碰撞、避让与支撑 | 检测材料是否占路、车辆和设备是否合理接地，检查建筑/设备之间非设计性穿透。 | 占路面积、漂浮/穿透实例、支撑关系满足率；塔吊等正常结构交接与地面接触单独处理。 |
| 视觉 Visual | 俯视可读性 | 检查主相机为约 60° 俯视正交视角，观察出入口、道路和三类作业区域是否能辨认；备用图展示同一场景的不同方位。 | 投影类型与视角偏差、关键区域可见率及盲评可读性；不限定原参考图的布局或配色。 |
| 视觉 Visual | 卡通风格与材质统一 | 评价低多边形造型、简洁色块、比例和材质的一致性；结合实际模型检查而非只看三角面数。 | 风格一致性辅助评分/人工偏好与具体缺陷；评审示意图不用于逐像素或几何真值比较。 |
| 任务与状态 Task & State | 文字要求与重复生成一致 | 逐项核对 brief；相同种子重跑，对比布局与几何，并从同一工程渲染两图。 | 文字要求满足率、重复生成差异、跨视图一致性；不要求提交可玩经营游戏或 UE 导航系统。 |
| 效率 Efficiency | 生成成本与反馈收益 | Harness 记录总耗时、token、工具调用、渲染次数及失败重试；若采用视觉反馈，分别记录初稿、每轮修改与最终结果，单次生成和最多 3 轮修改分组比较。 | 报告总成本、各轮指标变化及每次质量改善的额外成本；固定模型设置、环境和预算，不把失败运行从成本统计中删除。预算与综合权重待标定。 |

阈值依据英文 instruction；未明示项须在正式比较前标定。程序化、视觉辅助与人工结果分列，不合成未经校准的总分。运行失败保留原因；原生资产自检不代表完整 evaluator 已实现。

## 评分

本题最终得分：`60% vlm + 30% data + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
