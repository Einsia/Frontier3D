# 咖啡站·拉花中段

咖啡站·拉花中段 设计精品咖啡吧里单臂咖啡机器人拉花中途的近景场景，采用吧台斜上方近距离视角。咖啡吧台长 1.80 米、台面高 0.95 米、深 0.60 米，台面为浅色实木。台面从左到右布置：单头半自动咖啡机（宽 0.55 米、高 0.45 米，冲泡头下锁定一只咖啡手柄，压力表指针停在中段）、磨豆机（豆斗透明可见豆粒）、粉压器与粉杯座；吧台后墙上层搁板放咖啡豆袋三只与杯架一排。单臂机器人在台面后中央：基座高 1.00 米、臂展 0.85 米，末端两指夹爪持 0.35 升不锈钢奶缸，缸口悬在一只 250 毫升拿铁杯上方 0.03 米，缸体向杯倾斜 20°（±2°），缸嘴延长线指向杯内液面中心偏后三分之一处；杯中奶泡面已成形一片叶纹基底的静态浮雕面（可用贴图或浅浮雕几何），杯柄朝右 45°。杯列沿台面前沿排开四只、杯距 0.15 米，其中一只倒扣在沥水架上。可通行验收：吧台后操作位进深不小于 0.80 米，机器臂扫掠包络与搁板下沿净空不小于 0.15 米。可触及验收：冲泡头、磨豆机出粉口、杯列两端共四点距臂基座均不超过 0.80 米，高度在 0.90–1.40 米工作带内。可操作验收：奶缸倾斜方向与杯柄方向相背（避免手背碰撞的常见姿态），缸底最低点与搁板、杯列净空均不小于 0.05 米。使用暖木、黑色机器、黄铜细节与奶白杯具，侧窗暖光加吧面射灯，咖啡液面留一点高光。主视角把奶缸、拿铁杯液面与冲泡头收进近景浅景深画面。这是可编辑静态场景，不要求奶流、蒸汽棒喷气或杯体移动。

使用米制、Z 向上。创建可编辑、有实体厚度、合理支撑且语义部件可分离的三维几何。机器人须呈现指定关节结构与末端执行器的静态姿态，不要求控制器、动力学或操作轨迹。工作球用于几何可达包络核对，不等于逆运动学或动力学可行性证明。将当前冻结接触与其他服务目标区分，在场景及 README 标注服务点，不另放重复机器人。通行净宽以排除正在验收的机器人后的自由路径计入，其他家具及突出物全部计入障碍；在 README 给出路径采样点与测量口径。不能用照片平面替代完整场景。
