# 温室·番茄采摘机器人

温室·番茄采摘机器人 设计连栋温室里采摘机器人作业中的场景，采用沿种植行方向的斜上方视角。温室约 12 × 5 米，拱形骨架间隔 2 米，覆盖面留 40% 透光，地面为反光地布。两列种植槽平行布置：槽高 0.55 米、宽 0.40 米，行间净距（两槽相对内缘之间）1.50 米，行间通道净宽不小于 0.45 米并沿全程采样连续；番茄藤沿吊线向上生长 2.20 米，吊线张紧、每株一绳，叶群用成簇低多边形叶板组成立体叶冠，不得用单一交叉面片糊弄。其中一株挂一串六果番茄：串轴向下倾斜 20°，果径 0.05–0.07 米渐变，果梗汇入总梗。采摘机器人停在行间：履带底盘宽 0.60 米、接地长 0.90 米，车体上立六轴臂，臂展 0.90 米；末端为软吸盘加电动剪组，吸盘刚吸附在串中第二颗果上，吸盘口与果面接触环穿透不超过 3 毫米、吸盘轴线过果心，剪刀刃口张开 15°，位于果梗后方 0.02 米、两刃包住果梗截面。车体前格放采收筐，筐口 0.40 × 0.30 米、筐口高 0.40 米，筐内已有三颗果。可通行验收：履带外缘与两列种植槽净距各不小于 0.20 米，通道全程无藤蔓下垂侵入。可触及验收：目标果、串顶果、近侧通道中线三点距臂基座不超过 0.85 米，目标高度 0.80–1.60 米。可操作验收：吸盘—果面、剪刀—果梗两处接触同时成立，被吸果与相邻果间隙不小于 10 毫米。使用绿色藤叶、红果、米白种植槽与银灰履带车，上午阳光透过拱面在地面投出整齐的格状影。主视角同框机械臂、果串与行间通道，第二视角可顺行向远望整列藤架。这是可编辑静态场景，不要求果实脱落、汁液或藤蔓生长动画。

使用米制、Z 向上。创建可编辑、有实体厚度、合理支撑且语义部件可分离的三维几何。机器人须呈现指定关节结构与末端执行器的静态姿态，不要求控制器、动力学或操作轨迹。工作球用于几何可达包络核对，不等于逆运动学或动力学可行性证明。将当前冻结接触与其他服务目标区分，在场景及 README 标注服务点，不另放重复机器人。通行净宽以排除正在验收的机器人后的自由路径计入，其他家具及突出物全部计入障碍；在 README 给出路径采样点与测量口径。不能用照片平面替代完整场景。
