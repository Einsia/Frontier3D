# 评测接口：低角度光照下的月表景观

本题为开放式设计任务，唯一规范是 instruction.md 中的文字。私有参考展示可使用的形态和风格，不增加隐藏要求，不能直接用参考图相似度代表正确性。具体检查对象：灰色月壤、起伏陨石坑沿、大小岩块、远山与地球、低角度投影。

| 维度 | 指标 | 接入方法与边界 |
|---|---|---|
| 运行有效性 | 固定文件完整、入口成功、原生重渲染、缺失依赖数 | 仅挂载空 input 与英文题面，在清洁工作区运行约定命令；检查所有输出均在 output 内，禁止读取 solution。 |
| 需求覆盖 | 题面列出的设施、数量、范围、视图要求满足率 | 将英文题面的每个可验证要求拆为评测侧清单；数量按语义实例计数而非 Blender 对象数，不依赖对象名称。未要求的装饰不扣分。 |
| 几何与布局 | 支撑、连接、空隙、遮挡、明确尺度约束 | 从 evaluated mesh 世界坐标测量；题面明确的最小值和范围为约束，使用 1% 数值容差；“约”尺寸允许 ±10%。只对题面提及的关系设硬门槛。 |
| 空间合理性 | 穿插体积、悬浮距离、通路连通性 | 几何采样和 BVH 检测主要刚性构件；地形、埋入岩块和接合结构按语义排除预期相交。题面要求通路时做平面占据图及连通性检查，按题面净宽膨胀障碍。 |
| 形态与材质 | 主要结构具有体积、材质类别及照明要求 | 重新渲染深度/法线/实例遮罩；检查视差和轮廓。低多边形或写实要求按题面分别检查，不要求原作者拓扑或原资产识别。 |
| 双视图一致性 | 相机变化符合题面、两图同一几何 | 读取相机变换并重渲染；备用相机无目标图，不和私有示例任意相机逐像素比较。 |
| 可复现与编辑 | 入口二次运行一致、主要结构可编辑、资源自包含 | 同种子运行两次；比较几何/材质摘要。允许实例和程序修改器，不强制每个小零件独立对象。 |
| 效率 | 时间、token、工具调用、失败次数 | Harness 统一记录，质量和成本分开报告。 |

语义区域、几何与相机检查的实际范围以逐题配置为准；生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。视觉判断不能代替精确几何指标。风格项若尚无稳定判据，单列人工复核，不能冒充自动通过率。示例原生文件已通过依赖检查，但未逐条声称满足新题面全部设计约束，也不作为单一通过答案。

## 评分

本题最终得分：`60% vlm + 30% data + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
