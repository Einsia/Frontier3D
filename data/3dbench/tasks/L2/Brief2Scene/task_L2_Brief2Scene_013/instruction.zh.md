# 公寓楼道·配送机器人等电梯

公寓楼道·配送机器人等电梯 设计住宅楼电梯厅里配送机器人候梯的场景，采用电梯厅斜上方三分之四视角。电梯厅约 3.6 × 2.4 米，地面抛光石材并按 600 网格分缝，一侧墙面为信报箱组（12 格、总宽 1.80 米、底面高 0.30 米）。电梯门宽 0.90 米、完全开启，轿厢进深 1.40 米、宽 1.60 米，轿厢地坎与厅地面齐平、高差不超过 3 毫米，厢内三面可见扶手横杆（高 0.90 米）、操作盘与一面轿厢镜；厅门地坎导槽与轿厢地坎对齐偏差不超过 2 毫米。配送机器人停在厅中央候梯位：底盘 0.50 × 0.45 米，屏顶高 1.20 米，三层载物格，顶层托盘放一只 0.35 × 0.25 × 0.15 米的快递纸箱，箱面面单贴纸朝上；机身中线正对电梯门中线，偏差不超过 5°，机身前缘距门地坎 1.20 米。地面贴直径 1.50 米的候梯回转标圈，圈内除机器人外无障碍。可通行验收：从回转圈到电梯门的直线进厢路径净宽不小于 0.80 米，信报箱凸出与消防栓箱不得侵入；轿厢内净空满足机器人保守通行包络 0.75 米加两侧各 0.30 米余量。可触及验收：顶层托盘面高 0.85 米，与轿厢操作盘（高 1.10 米）构成可达操作面集合，另行标记进入轿厢后的控制服务位，服务位至操作盘距离不超过 0.90 米且无阻挡；提交场景仍保持门外 1.20 米的候梯姿态。可操作验收：纸箱中心与托盘中心对齐偏差不超过 20 毫米，箱体不悬挑出托盘边缘。壁灯暖光 3000K 加轿厢顶灯外泄。主视角同框机器人、敞开的电梯门与轿厢纵深；第二视角可从轿厢内向外望。这是可编辑静态场景，不要求电梯运行或机器人进出动画。

使用米制、Z 向上。创建可编辑、有实体厚度、合理支撑且语义部件可分离的三维几何。机器人须呈现指定关节结构与末端执行器的静态姿态，不要求控制器、动力学或操作轨迹。工作球用于几何可达包络核对，不等于逆运动学或动力学可行性证明。将当前冻结接触与其他服务目标区分，在场景及 README 标注服务点，不另放重复机器人。通行净宽以排除正在验收的机器人后的自由路径计入，其他家具及突出物全部计入障碍；在 README 给出路径采样点与测量口径。不能用照片平面替代完整场景。
