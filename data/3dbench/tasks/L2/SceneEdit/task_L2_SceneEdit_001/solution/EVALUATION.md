# 评测接口与指标

本题目标：浴缸内部凹腔、连续外壳、圆滑口沿及与地面的接触。完整模型用于可见目标形状与保留区域的参考，不要求提交者复现原始对象名称和任意网格拆分。annotations/legacy-target-index.json 是评测侧定位索引；其中旧包围盒和名称不能成为未向模型公开的额外硬约束。

| 维度 | 指标 | 实现与边界 |
|---|---|---|
| 可执行性 | 代码运行、原生加载、重渲染成功率；缺失依赖数 | 按 instruction 的固定入口在清洁副本执行；核对 output 路径、Cycles 和初始场景设置。 |
| 结构 | 目标语义部件覆盖率、独立可编辑性 | 按本题自然语言描述检查目标组成；不用原对象数或名字作硬门槛。 |
| 几何 | 目标表面距离、轮廓差异、支撑与穿透 | 与参考目标计算采样表面距离，按目标尺寸归一化；另测凹腔/空隙、厚度及相接关系，AABB 只能粗筛。隐藏细节不做精确形状要求。 |
| 保持性 | 非目标几何、变换、材质、纹理、灯光、主相机保持率 | 初始文件与输出对照。允许等价网格表达，先查哈希，再用表面与实际着色比较；不要仅因顶点顺序变化判错。 |
| 视觉 | 主视角目标轮廓、材质与阴影；非目标像素漂移 | 从提交 scene.blend 重渲染，分目标、接触阴影和其余区域报告。图像分数与几何分数分开；目标遮挡和阴影的合理变化不应算非目标编辑。 |
| 状态一致性 | 双视图来自同一真实三维场景 | 核对备用相机局部 X 平移 0.30 m，旋转和镜头不变；禁用按相机切换目标形状的做法。备用图只作结构诊断，不匹配历史作者备用图。 |
| 效率 | 生成耗时、token、工具调用、渲染、失败重试 | Harness 记录，保留失败成本；固定预算，不能将效率与质量混成未经校准的总分。 |

solution/reference/scene.blend 是完整参考；environment/input/initial.blend 是保留性基线；reference/beauty.png 是主视角参考。优先核对执行、真实几何与保持性，再报告视觉质量。生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。几何阈值与视觉判断仍有校准限制。

## 评分

本题最终得分：`20% numeric + 20% preservation + 20% vlm + 30% target + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
