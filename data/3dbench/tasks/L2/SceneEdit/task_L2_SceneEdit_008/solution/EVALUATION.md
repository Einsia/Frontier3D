# 评测接口：赛车场：补建维修站与带顶看台

补件目标：对可见轮廓、真实三维表面、接触和孔洞分别评分。参考对象索引只供评测侧定位，不要求相同对象名称、对象数或拓扑。隐藏表面合理即可。

| 维度 | 指标 | 实现方式 |
|---|---|---|
| 可执行性 | 固定输出完整、入口执行、原生重渲染及依赖有效 | 按 instruction 约定入口从干净输入执行；检查图片来自提交工程。 |
| 需求覆盖 | 成排维修车库、端部办公空间、阶梯看台与悬挑顶、赛道两侧布局和入口净空 | 用题面语义清单逐项检查；评测侧先标注目标区域，不用模型任意命名判断。 |
| 局部效果 | 目标结构/颜色/照明恢复程度 | 原生完整工程和 reference.png 为私有目标；分目标区域与全局报告，不用简单全图平均掩盖局部失败。 |
| 保持性 | 非目标对象、几何、变换、材质、灯、相机、渲染设置保持率 | 对照 initial.blend 和 preserved-baseline.json；先哈希粗查，再在有必要时验证语义等价，避免顶点排序改变误判。 |
| 空间一致性 | 接触与穿透、深度层次、备用视角一致 | 几何题用 BVH、轮廓与表面采样；灯光/材质题核对原几何完整保留。备用图不要求匹配隐藏目标图。 |
| 视觉 | 区域轮廓、Lab 颜色分布、亮暗层次和阴影 | 在同相机重渲染，不要求单个噪点一致；合法目标引起的间接反射及接触阴影变化不算非目标编辑。 |
| 可复现性 | 同输入重复运行一致、资产自包含 | 验证第二次运行以及离线重开工程；禁止读取私有完整模型。 |
| 效率 | 时间、token、调用与失败成本 | Harness 统一记录，和质量分开。 |

annotations/pair-audit.json 记录数据制作时移除的对象或改变的参数，preserved-baseline.json 记录输入状态。二者均不提供给模型。生成与测评由仓库公共入口执行，最终计分见[评分说明](../../../../../../../docs/cn/scoring.md)。容差与视觉权重保留校准限制；未实现指标不得写成已测分数。

## 评分

本题最终得分：`20% numeric + 20% preservation + 20% vlm + 30% target + 10% detail`。各分项定义与取证流程见[评分说明](../../../../../../../docs/cn/scoring.md)。

内容缺失、形状或布局偏差降低相应质量分；技术故障及必需证据缺失保留未完成状态，不能补零或重分配权重。交付、执行、加载、依赖及真实性按题目合同独立检查。评分采用绑定的真实场景重渲染证据，保留提交图片与不一致诊断。

数值检查仅覆盖已实现且有证据的指标，未实现的精确计数不视为达标。视觉判断不能证明隐藏几何、真实接触或完整物理正确性；参考区域和感知评分仍有校准限制。
